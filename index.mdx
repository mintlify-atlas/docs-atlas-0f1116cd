## What Bookmarks does

Every page load fetches the same dataset from Upstash Redis — no per-user state, no login wall. Anyone with the URL can browse and add links. Destructive or editorial actions (edit, delete, import, reset) require an admin password you set at deploy time.

<Steps>
  <Step title="Fork or clone the repo">
    Push the project to your own GitHub repository so Vercel can deploy it.
  </Step>
  <Step title="Create an Upstash Redis database">
    Create a free database at [upstash.com](https://upstash.com) and copy the `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` values.
  </Step>
  <Step title="Deploy to Vercel">
    Import the repo in Vercel, add the two Redis env vars plus `ADMIN_PASSWORD`, and click **Deploy**.
  </Step>
  <Step title="Share the URL">
    Your live bookmark page is ready. Share the Vercel URL — all visitors see the same list and can add links immediately.
  </Step>
</Steps>

  <Card title="Folder Organization" icon="folder">
    Group links into folders with custom emoji, color labels, and pin-to-top support.
  </Card>
  <Card title="Command Palette" icon="magnifying-glass">
    Press **⌘K** (or **Ctrl+K**) to open a fuzzy-search palette over every link and action.
  </Card>
  <Card title="Admin Panel" icon="lock">
    Password-protected admin mode unlocks editing, deleting, import/export, announcements, and folder pinning.
  </Card>
  <Card title="Click Tracking" icon="chart-bar">
    Every link open increments a click counter. A Most Visited bar surfaces your top eight links automatically.
  </Card>
  <Card title="Import / Export" icon="file-export">
    Back up and restore your full dataset as JSON or export a Netscape-format HTML file compatible with all major browsers.
  </Card>
</CardGroup>
